# Dataset Source Notes

**Project:** Learner Performance Prediction & Early Learning Support Dashboard
**Client:** Career Solutions (EduTech)
**Prepared by:** Monish T

## Origin: SYNTHETIC DATA
No real learner records were used. All rows in `synthetic_learner_data.csv` were generated by
`generate_synthetic_data.py`. Model performance on this data demonstrates that the implementation
works. It does not demonstrate effectiveness on real learners.

## Reproducibility
- Generator: `generate_synthetic_data.py` (NumPy `default_rng`, seed = 42)
- Running it again produces a byte-identical CSV (verified by checksum comparison).
- Benchmark (`BENCHMARK = 50`) is a project assumption and is configurable.

## Contents
| Item | Count |
|---|---|
| Total rows | 1,560 |
| Observed final assessment | 1,500 |
| Withdrawn before week 6 | 40 |
| Missing assessment | 20 |

One enrollment per learner. `enrollment_id` and `learner_group_id` are anonymous and must be
excluded from model features. They are kept for row matching and split control.

## How the data was built
- Week-2 activity features were generated from two hidden traits (engagement and ability) that are
  correlated. Those traits are not saved in the file.
- `final_score` is a weighted combination of the week-2 features, a small course-category effect and
  random noise, so outcomes overlap between classes and no model can be perfect.
- `below_benchmark = 1` when `final_score < 50`, else 0.

## Deliberate data-quality features (to be handled on Day 3)
- `quiz_average` is blank where no quiz was completed before the cutoff. A small number of genuine
  0.0 scores also exist. These must stay distinct: blank is not zero.
- Withdrawn and missing-assessment rows have blank `final_score` and `below_benchmark`. They are
  reported separately and are excluded from score-model training and evaluation. They must never be
  labelled zero or below benchmark.
- Values at exactly 100 occur for percentage features because of range clipping.

## Limitations
- Relationships between features and the score are assumptions built into the generator, not
  findings about real learners.
- The data comes from a single synthetic cohort, so it supports no claim about future cohorts.
- Course-category differences are arbitrary and set by the generator.
